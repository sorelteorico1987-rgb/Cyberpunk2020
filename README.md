# NEON 2020 — Ecos de Night City

Proyecto académico de Programación II en C# (.NET 10), inspirado en el universo de Cyberpunk 2020.

## Objetivo
Demostrar abstracción, encapsulación, herencia, polimorfismo, validación de entradas y funcionamiento de un juego de rol narrativo por consola.

## Ejecutar

```bash
dotnet run
```

## Autopruebas

```bash
dotnet run -- --autoprueba
```
